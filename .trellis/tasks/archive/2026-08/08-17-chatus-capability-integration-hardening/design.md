# Capability Integration Hardening Design

## Verification Shape

This child should add implementation code only when a cross-layer gap cannot be
fixed in its owning completed child without reopening that task. Prefer focused
fixtures and contract matrices over duplicate runtime paths. Tests must prove
one admission per user message, exact Provider/MCP execution counts, assignment
and review rechecks immediately before I/O, authoritative cancellation, and
complete terminal settlement.

## Lifecycle And Privacy

Exercise conversation creation, edit/resend, regenerate, follow-up, branch,
sharing/ACL denial, deletion, member export, administrative capture, and restore.
Normalized private vision evidence follows source-image ownership; citations
follow the visible answer/output contract. Aggregate/log scans assert only the
explicit content-free dimensions are retained.

## Specification Capture

Update the smallest applicable files under `.trellis/spec/` with exact enums,
omission semantics, execution ordering, failure behavior, lifecycle ownership,
and named tests/commands. Do not change protected release-observation or legacy
rollout artifacts.

## Delivery

Run quality commands serially in the documented order. `wrangler deploy
--dry-run` is packaging validation only, not deployment. Final review compares
the complete diff to parent AC1-AC12 and asserts protected boundaries.
