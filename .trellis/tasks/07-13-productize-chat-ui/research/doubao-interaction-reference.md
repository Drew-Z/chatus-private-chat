## Supported Observations

The fetched article explicitly describes:

- A redesigned new-conversation homepage with more natural typography and a simpler visual presentation.
- Automatic conversation-list grouping.
- Common task/function entries surfaced on the conversation homepage.
- Refinements to the current conversation interface, including result feedback placement.
- A `/` quick menu.
- More flexible partial-conversation sharing.

## Application To Chatus

Use only the interaction principles that match the current product:

- Improve the new-chat task starting point.
- Keep conversation grouping easy to scan.
- Surface existing common actions more clearly.
- Refine current-conversation feedback/action placement.

Do not copy Doubao's visual identity. `/` commands, new sharing behavior, agents, and other new capabilities are out of scope for this pass.

The source is a third-party review hosted on the Volcano Engine developer community, not a formal Doubao design-system specification. Treat it as directional evidence rather than an exact implementation contract.
